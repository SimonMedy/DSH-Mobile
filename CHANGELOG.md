# Changelog

All notable changes to DSH Mobile will be documented here.

The project follows semantic versioning.

## [0.1.0] - 2026-08-18

### Added

- React Native + TypeScript cross-platform application shell for Android and iOS.
- Multiple named DSH server profiles with default-server behavior and launch configuration.
- Structured server editor with security classification and connection testing.
- Hardened DSH WebView navigation boundary, popup routing, crash recovery, and retry UI.
- Local versioned persistence, legacy migration, corruption recovery, and explicit local-data reset.
- Unsaved-editor protection and explicit public-HTTP confirmation.
- Strict structured Host-field validation and consistent first-server default behavior.
- Official DeepSeek design system tokens (`#0A0A0A`, `#6799FE`, `#4D6BFE`), cosmic ocean ambient aura, and pill buttons.
- Official DSH Mobile whale branding assets and true Android Adaptive Icons (with 60% safe-zone calibration and Material You monochrome support).
- Theme-adaptive in-app header logo (high-contrast white whale in dark mode, blue whale in light mode).
- Settings screen with direct links to DeepSeek Harness website, upstream GitHub, and project repository.
- Full Docker and Make workflow for reproducible builds (`make check`, `make build`, `make dev`).
- Public-repository engineering, security, CI, contribution, and release documentation.
